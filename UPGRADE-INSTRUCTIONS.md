# Upgrade the same GitHub project

1. In Supabase, open SQL Editor, paste all of `SUPABASE-SETUP.sql`, and click Run.
2. In your current GitHub repository, upload every file in this package and replace matching files.
3. Keep the repository and GitHub Pages settings you already have.
4. In Supabase go to Authentication > URL Configuration.
5. Put your exact GitHub Pages URL in Site URL and Redirect URLs.
6. Wait for GitHub Pages to redeploy, refresh, and create an account.
7. The app will offer to import the data saved by your original version.

This adds separate user accounts, cloud data, custom commitments, custom days, custom time, reminder intensity, accountability voice, optional money goal, login/logout, and password reset.

Reliable notifications after an iPhone fully closes the app still require a later backend push-notification phase.
